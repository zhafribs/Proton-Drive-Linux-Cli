## Changes

- About → Copy diagnostics prints the key-revocation feed URL and whether the
  running build trusts it.
- An untrusted-feed update error now says to download the latest release
  manually.
- Settings shows the same warning if the running build's allowlist rejects its
  own feed.

## Verification

- 316 tests passed, 3 ignored in the GUI binary; clippy clean.
- CI run `43414026586`: verify and release succeeded.
- Release assets are present with the signed `SHA256SUMS` covering all five.
- Published `3.31.1` is the first version that can fetch the feed; `3.31.2`
  is the target used to exercise that path.

## Upgrade path

1. Manually install `3.31.1` or `3.31.2` once.
2. Check About/`--diagnose` reports the new version.
3. From `3.31.1`, update to `3.31.2` in-app; the feed fetch and signature
   verification must succeed before the download starts.
