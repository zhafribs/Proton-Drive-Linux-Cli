# Release evidence — v0.9.0-gui3.33.5

Tag: v0.9.0-gui3.33.5
Purpose: make the Photos “needs attention” hold actionable instead of a
warning with no user-facing remedy.

## Changes

- Added a card under the Photos hero when the photo summary needs attention:
  - **Open photo folder** — inspect or move the stale local copies.
  - **Retry** — request another photo pass.
  - **Reset baseline** — only for the incomplete-timeline hold.
- **Reset baseline** opens a confirmation dialog, then:
  - archives `photos-state.json` and `photos-sync.json` with a timestamp,
  - removes `.proton-photos-hold`,
  - starts a fresh photo pass.
  - It does **not** delete any photo file. The dialog explains that local
    photos left in the folder will be uploaded again, so a cloud deletion
    needs the stale local copies removed first.
- Both English and Bahasa Melayu strings were added.
- UI audit renders the card at 720×400 in both languages.
