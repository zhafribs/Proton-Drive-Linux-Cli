## Sync reliability changes

- `is_network_error` recognises timeouts, DNS/TLS/proxy/connection failures;
  `failure_status` keeps those as `error`, never `needs_login`.
- Network failures retry after 30 s; session failures after 10 s. A successful
  cycle clears either status by itself.
- `Cli::warm_session` runs one `fs info` under the app-wide lock before any
  parallel transfer batch. A dead session fails before workers start; an
  expired access token is refreshed once instead of by several workers at
  once (the CLI rotates the refresh token on every use).
- `--diagnose` and About → Copy diagnostics now include the health error,
  failure kind, cycle timing and recent engine log lines.
