# Release evidence — v0.9.0-gui3.33.2

Tag: v0.9.0-gui3.33.2
Purpose: use the measured current window size as the first-open default and
persist the user's resizes without waiting for a clean quit.

## Measured window

The running Proton Drive window (`xdotool`, 100% interface scale) was:

```
X=511 Y=65 WIDTH=818 HEIGHT=747
```

This is a client area of **818×747** physical pixels.

## Changes

- `Prefs::load` now defaults to **818×747** instead of 940×780 when no
  `window_size` has been saved. The layout floor still clamps it at smaller
  scales or bogus values.
- The user's current `window_size` was written as `818x747`, so the next
  launch restores the size shown now.
- `persist_size_when_settled` saves a resize after it has been stable for two
  seconds. Hiding to tray and quitting still save immediately. A crash no
  longer loses the last user-chosen size.
- Test: a missing `window_size` loads as `(818, 747)`.
