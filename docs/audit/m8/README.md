# M8 screenshot matrix

Generated by `scripts/ui-check.sh` from the same `App::draw` path the real
window uses, with demo data and no network, tray or service.

- `*-100-720x400.png` — every page at the minimum window (720×400).
- `*-50-720x400.png` — 50% interface scale; the logical layout is 1440×800.
- `*-200-1440x800.png` — 200% interface scale; the logical layout is 720×400.

The test also fails on any input widget without an AccessKit name, and a
separate test Tab-focuses the Settings nav row and activates it. These images
are evidence and a review surface, not pixel-perfect golden files: GPU and
font rendering differ between machines.
