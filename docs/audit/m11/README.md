# M11 Malay screenshot matrix

Generated by the `malay_screenshot_matrix` audit test with the language
forced to Bahasa Melayu for the test thread. Every page is rendered at
1024×720 through the same `App::draw` path as the real window, with demo data
and no network, tray or service.

The matching English matrix is `docs/audit/m8/`. File names, versions, sizes,
dates and keyboard key names stay as data; everything the app says is in the
Malay catalog.
