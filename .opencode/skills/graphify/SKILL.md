# Graphify (Knowledge Graph Analysis)

Use `graphify` whenever you need to analyze codebase architecture, file relationships, god nodes, or dependencies.

## Key Capabilities
- Builds and queries a knowledge graph of files, functions, structs, and dependencies.
- Explains complex architectural paths and detects hidden coupling.
- Answers "how does X interact with Y" using graph traversal.
