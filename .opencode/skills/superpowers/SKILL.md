# Superpowers (Spec-Driven Development)

Acts as a spec-driven development wrapper that guides feature creation through structured phases before coding.

## Workflow
1. **Brainstorm & Clarify**: Ask high-yield questions to discover edge cases and domain rules.
2. **Design Spec**: Draft architecture, boundaries, and data shapes in a spec file.
3. **Implementation Plan**: Break work into thin, verifiable slices.
4. **Execute**: Code against the spec and verify success criteria.
