# Understand Anything

Maps existing files, functions, structs, and modules into a queryable structure to prevent breaking existing behaviors.

## Usage
- Inspect module boundaries and caller graphs before modifying shared code.
- Trace data flow across GUI, engine IPC, and Proton CLI subprocess interfaces.
- Uses `graphify` and code search tools under the hood.
