# Find Skills (Vercel Ecosystem)

Discovers and recommends tools or community skills tailored to the project stack.

## Usage
- Search available skills in OpenCode and harness registry.
- Recommend specialized skill profiles for Rust, egui, Linux desktop, or Proton integrations.
